## 🚀 Featured Projects

### [LaneDetector — Real-Time Lane Detection in C](https://github.com/NikitaSch2004/LaneDetector)
> **Stack:** C, OpenMP, SIMD (ARM NEON), POSIX threads, FFmpeg pipes, no OpenCV  
> Lane detection pipeline written from scratch: Canny edge detector, Hough transform and temporal smoothing. Profiled and optimized stage by stage to **~700 FPS on 720p video** (8× faster than the first in-memory version, on par with OpenCV for the same steps), with every optimization verified frame by frame. The whole program runs 10–15× faster than real time and is limited only by the hardware video encoder.
